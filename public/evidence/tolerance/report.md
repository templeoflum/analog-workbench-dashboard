## Decision and limits

Keep the coupled reference experimental. Tightened joint tolerances fail across all six configurations; this study does not establish the cause or resolve those failures. Next bounded investigation: use identical-circuit, single-component substitution diagnostics to locate the sensitive model boundary. Do not silently relax tolerances or freeze the reference and call that full-model validation. Hardware measurements, power-network qualification and full operating-domain coverage remain outstanding.

## Repeat and provenance

Extract the archive, retaining sibling folder names. Set XYCE_EXECUTABLE and XYCE_LIBRARY_DIRECTORY for a separately installed Xyce build, then run study.py in the tolerance f1 folder. Run verify_comparisons.py with NumPy available for the independent check. The source f1 folder contains core.py, supporting scripts, unchanged TI models plus documented TL074 syntax normalization, runtime metadata, and six nominal baseline waveforms. The tolerance folder contains its copied models, exact netlists, simulator logs, result records and scripts. Raw new traces are regenerated by the study. No simulator binary is included. Runtime metadata paths describe this machine, so use environment overrides elsewhere.

The separate tolerance f0 attempt failed before simulation because unquoted absolute include paths contained spaces. It is preserved locally as a harness failure and excluded from the 18 numerical attempts here. Relative include paths corrected that harness issue in f1. No research result was inferred from those parser failures.
